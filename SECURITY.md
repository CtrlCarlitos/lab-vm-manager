# Security Policy

## Supported Version

Only the latest revision on `main` is supported with security fixes.

## Reporting a Vulnerability

Report a suspected vulnerability through [GitHub private vulnerability reporting](https://github.com/CtrlCarlitos/lab-vm-manager/security/advisories/new).

Do not open a public issue for an undisclosed vulnerability. Please include the affected version or commit, environment details, reproduction steps, potential impact, and any suggested mitigation. Avoid public disclosure until a fix is available and coordinated disclosure is appropriate.

Reports will be reviewed and acknowledged as maintainer availability permits. Response and remediation time depends on the issue's impact, complexity, and reproducibility.
